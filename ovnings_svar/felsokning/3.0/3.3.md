3.3 Testet som är avstängt

Symptom
Ett test i billing.test.ts är avstängt med it.skip. Kommentaren säger att det faller runt midnatt på grund av tidszoner, och att Gorm vet detaljerna (#52).

Återskapa

1. Skapa en egen branch.
2. Ändra it.skip( till it( i apps/api/src/legacy/billing/billing.test.ts, rad 29–33.
3. Kör npx vitest run apps/api/src/legacy/billing/billing.test.ts.

Hypoteser

- Testet faller bara runt midnatt. Test: körde det mitt på dagen. Resultat: faller ändå. Föll.
- Gorm vet detaljerna. Test: git log --author=Gorm. Resultat: Gorms sista commit är 2022-12-21, testet skrevs 2023-10-10. Ingen kunde fråga honom. Föll.
- #52 förklarar felet. Test: git log --grep="#52". Resultat: #52 handlar om kurirens körschema, inte avgifter. Föll.
- Koden räknar fel. Test: läste felutskriften. Resultat: expected 0, received 1. Höll.

Rotorsak
lateDays i apps/api/src/legacy/billing/billing.ts returnerar out.diff(pickup, 'days') + 1. Hämtar man på avtalad dag blir det 1 sen dag. Testet visar ett riktigt fel, men stängdes av med en förklaring som aldrig kontrollerades.

Åtgärd
Ta bort + 1 och slå på testet igen. Kontroll: testet går igenom, och hämtning på avtalad dag ger ingen förseningsavgift.

Vilket fel döljer testet?
Kunder som hämtar sitt monster på avtalad dag får betala en dags förseningsavgift.
