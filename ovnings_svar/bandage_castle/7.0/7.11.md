# 7.11 Labb: Från issue till kod

**Issue:** #7, Species search doesn't find "dragon". Märkt good first issue.

**Gren:** fix/species-search

**Återskapa:** som keeper på Species gav sökningen dragon ingen träff, men Dragon gav träff.

**Orsak**
apps/web/src/pages/species/SpeciesListPage.tsx, rad 14. Logiken kollade inte små bokstäver, bara exakt det som var sparat. Sökningen jämfördes med värdet exakt med includes, så 'Dragon'.includes('dragon') blev false. git blame visade att raden kom in med commiten 6eb8344 från Tobias Fenwick 2023-04-11, "Add search box to species compendium". Meddelandet säger bara att en sökruta lades till, och det fanns inget test.

**Test före lagningen**
Claude Code skrev SpeciesListPage.test.tsx, som söker på Dragon, dragon, DRAGON och sheep. Resultat: 3 failed, 1 passed. Bara Dragon gav träff.

**Lagningen**
Sökordet, namnet och dieten görs om till små bokstäver med toLowerCase innan jämförelsen. Commit-meddelandet innehåller Closes #7.

**Test efter lagningen**
4 passed.

**Behövde jag rätta Claude Code?**
Ja. Claude pushade testet till en gren med samma namn som min lokala, fix/species-search. När jag körde testet fick jag "No test files found", eftersom min lokala gren inte hade filen. Jag hämtade Claudes version med git pull origin fix/species-search.
