# 3.7 Pengar och tid är svårare än de ser ut

**Decimaltal i Node**
node -e "console.log(0.1 + 0.2)" gav 0.30000000000000004, inte 0.3.

**Vilka tabeller följer ADR-006?**
git grep på \_copper och Copper i prisma/schema.prisma gav subtotal, total, unit och amount två gånger. Alla ligger i Billing v2: InvoiceV2, InvoiceLineV2 och PaymentV2. De lagrar koppar som heltal.

git grep på Decimal gav ganska många fler. Belopp i guld som decimaltal finns i Stay (dailyRate), Invoice (total), InvoiceLine (unitPrice, amount), Payment (amount), CourierJob (fee) och HiringListing (feeGold). De följer inte ADR-006. SupplyMovement (change) är också Decimal, men det är en mängd i lagret, inte pengar.

Bara de tre tabellerna i Billing v2 följer ADR-006. Sex tabeller lagrar fortfarande guld.

**Vad händer när kod som räknar i koppar möter en kolumn som lagrar guld?**
Det blir konstiga tal, eftersom kopparkoden tolkar guldet fel. I Felsökning 6.2 gav formatCopper(564.55) texten 5.64.54999999999995 gp. Och 564.55 guld lästa som koppar blir bara 5.64 guld, alltså hundra gånger för lite.
