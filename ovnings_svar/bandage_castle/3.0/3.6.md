# 3.6 Byt ut gammalt bit för bit, strangler fig

**Vilka legacy-filer har raderats?**
git log --diff-filter=D gav bara en: apps/api/src/legacy/auth/auth.routes.ts, raderad av Priya Valdez 2023-03-01 i "feat(auth): multiple roles per user and httpOnly cookie sessions". Auth är den enda modul som flyttats helt och tagits bort.

**Vilka funktioner finns på båda ställena?**
customers, monsters, reports och stays finns i både legacy och modules. Dessutom billing i legacy och billing-v2 i modules. Både nya och gamla används. Legacy monteras sist i app.ts, så de nya routes vinner, och det de inte tar hand om går vidare till legacy. För stays står det i app.ts att resten av /api/stays ligger i legacy.

**Hur långt har migreringen kommit?**
ADR-004 satte slutet av 2023 som mål och säger att det inte ska finnas mysql2-imports efter det, men ADR-004 följs inte riktigt. Sju mappar finns kvar i legacy, och README säger att de flesta fortfarande används.

**Varför stannade den?**
Gorm, som skrev legacy och billing, slutade. Sedan har många regler tillkommit i efterhand, och fokus har legat på ny funktionalitet. Man kanske tänkte att någon annan skulle sköta flytten, men inget gjordes.

**Har README:s regel följts?**
README säger att när man flyttar en modul till Prisma tar man bort den i legacy och uppdaterar ADR-004. Customers har flyttats, app.ts säger "replaces legacy/customers (ADR-004)", men legacy/customers finns kvar och README säger fortfarande "Still used: yes". Flyttar man så tar man bort den gamla, men den gamla finns kvar.
