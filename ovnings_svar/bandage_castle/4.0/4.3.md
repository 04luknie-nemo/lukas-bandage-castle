# 4.3 Ett anrops resa genom app.ts

```mermaid
flowchart TB
    req([Anrop in]) --> json[1. express.json<br/>läser JSON-kroppen]
    json --> cookie[2. cookieParser<br/>läser cookies]
    cookie --> auth[3. authenticate<br/>sätter req.user]
    auth --> mod[4. Modulernas routrar<br/>/api/lairs, /api/courier ...]
    mod --> legacy[5. Legacy-routern<br/>/api]
    legacy --> err[6. errorHandler<br/>gör om fel till JSON]
```

| Anrop             | Svar                                   | Passerade       | Stoppades                                                                                                                                      |
| ----------------- | -------------------------------------- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| /api/health       | 200, {"ok":true}                       | Steg 1, 2 och 3 | I health-routen i app.ts, som svarar direkt med res.json. Når aldrig modulerna, legacy eller errorHandler.                                     |
| /api/finns-inte   | 404, HTML "Cannot GET /api/finns-inte" | Steg 1 till 5   | Ingen router matchade. Inget fel skickades, så errorHandler kördes inte. Express svarade med sin inbyggda 404-sida i HTML.                     |
| /api/courier/jobs | 401, {"error":"Please log in"}         | Steg 1 till 4   | authenticate släppte vidare utan req.user. requireRole i courier-routern skickade UnauthorizedError, och errorHandler gjorde om det till JSON. |

**Var stoppades det sista, och varför?**
I steg 4, i requireRole, eftersom jag inte var inloggad och inte tillåten. authenticate stoppar aldrig själv, den sätter bara req.user om cookien finns.

**Vad jag lärde mig**
Formatet på svaret visar vilken väg anropet tog. JSON från health kommer från routen själv. HTML från finns-inte betyder att errorHandler aldrig kördes, eftersom errorHandler bara körs när någon skickar ett fel med next(err). Det är en lucka: en okänd adress ger HTML i stället för JSON.
