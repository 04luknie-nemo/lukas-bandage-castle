# 2.3 API:ts skelett

| Del         | Vad finns där                                                                                                                                                              |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| db/         | En fil, prisma.ts, som skapar Prisma-klienten.                                                                                                                             |
| errors/     | En fil, httpErrors.ts, med alla olika API-fel, till exempel NotFoundError.                                                                                                 |
| middleware/ | Fyra filer som körs i pipelinen: asyncHandler fångar async-fel, errorHandler gör om fel till JSON, requireRole kontrollerar roll och validate kontrollerar indata med zod. |
| utils/      | Två filer, formatGP och formatGold, som formaterar pengar.                                                                                                                 |
| types/      | En global typfil för Express, express.d.ts, som lägger till req.user.                                                                                                      |
| modules/    | Många mappar, en per funktion, med routes, service, schema och tester.                                                                                                     |
| legacy/     | Allt gammalt från före 2023, blandat med routes, middleware och db. SQL skrivs för hand med mysql2.                                                                        |
| index.ts    | Startpunkten. Startar servern, korpen och jobben.                                                                                                                          |
| app.ts      | Bygger appen och kopplar ihop express, auth, alla routes och errorHandler.                                                                                                 |
| config.ts   | Inställningar för programmet, som port, jwtSecret och namnet på cookien. Läser från process.env.                                                                           |
| env.ts      | Läser in .env-filen till process.env med dotenv. Prisma läser samma .env i roten.                                                                                          |

**Skillnaden mellan index.ts och app.ts**
index.ts startar servern med jobben och korpen, medan app.ts bygger appen med alla routes, auth och så vidare, utan att starta något. De är uppdelade för att testerna i app.test.ts ska kunna göra createApp() och skicka anrop med supertest, utan att starta en server eller jobben.

**Skillnaden mellan config.ts och env.ts**
env.ts laddar .env-filen. config.ts använder värdena. env.ts körs först, på första raden i index.ts.
