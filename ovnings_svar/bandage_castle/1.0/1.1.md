# 1.1 Installera och starta

Jag följde README steg 1 till 7 på Windows i PowerShell.

**Steg 1, Node.** README säger Node 26 LTS, men jag hade 24. Jag var osäker på om jag behövde uppgradera. npm run setup gav bara en varning och allt fungerade med 24. README säger inte att 22 till 25 går att köra med en varning, det står först i scripts/setup.ts (se 1.2).

**Steg 2, databasen.** README säger bara "öppna MySQL command-line client". Det står inte var den finns eller att man loggar in med root-lösenordet från installationen.

**Steg 3, .env.** Tydligt. Kommandot för PowerShell finns med, och tipset om specialtecken i lösenordet är bra.

**Steg 4 till 7.** npm install, npm run setup och npm run dev fungerade utan problem. Webben startade på localhost:5173 och jag kunde logga in med castle123.

**Förbättring av README:** skriv vilka Node-versioner som fungerar, och hur man öppnar MySQL-klienten på Windows.
