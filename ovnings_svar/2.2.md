# 2.2 Hitta filen

## Kom igång

Inloggningssidan i webbappen
Gissning: src/pages/LoginPage
Rätt: apps/web/src/pages/LoginPage.tsx
Metod: git ls-files | grep -i login

Databasschemat
Gissning: apps/web/prisma, sedan apps/prisma
Rätt: prisma/schema.prisma
Metod: git ls-files | grep -i schema
Kommentar: Prisma ligger i roten eftersom schemat används av mer än API:t: migrationerna, seed och setup. Package.json i roten pekar ut det. Filerna *.schema.ts i modules är zod-validering av API-anrop, inte databasen. legacy/db/schema.sql är legacys egen beskrivning av samma databas, så det finns två källor till samma sanning.

Skriptet för npm run setup
Gissning: tsconfig
Rätt: scripts/setup.ts, utpekad i package.json under "scripts"
Metod: grep -n '"setup"' package.json

ADR om pengar i koppar
Rätt: docs/adr/006-money-as-copper.md
Metod: git ls-files docs | grep -i adr

404-sidan
Gissning: apps/web/src/pages
Rätt: apps/web/src/pages/NotFoundPage.tsx, kopplad i App.tsx med <Route path="*">
Metod: git ls-files apps/web | grep -i notfound, sedan git grep NotFoundPage

## Lite svårare

Rollkontroll för API-anrop
Gissning: någonstans i api, sedan middleware/requireRole.ts
Rätt: apps/api/src/middleware/requireRole.ts
Metod: git ls-files apps/api/src/middleware
Kommentar: Legacy har ingen gemensam kontroll. Varje route jämför req.user.role med 'STAFF' och 'ADMIN' och svarar 403 "no".

Menyval per roll
Gissning: auditRole, sedan web/src/nav
Rätt: apps/web/src/nav/navConfig.ts
Metod: git ls-files apps/web/src/nav
Kommentar: Menyn styr bara vad som syns. Behörigheten kontrolleras i API:t med requireRole. Supplies länkar till /supply men routen heter /supplies, där sitter orsaken till supplies-buggen.

Migrationen för personalens skift
Gissning: prisma/migrations, något med rota
Rätt: prisma/migrations/20251125100000_rota/migration.sql
Metod: git ls-files prisma/migrations | grep -i rota

Demodata för monsterarterna
Gissning: prisma/seed/data, något med species
Rätt: prisma/seed/data/species.ts
Metod: git ls-files prisma/seed | grep -i species

## Kvar

- Sidan som visar en enskild faktura, två stycken.
- Utmaningen: alla funktioner som formaterar guld till text.
