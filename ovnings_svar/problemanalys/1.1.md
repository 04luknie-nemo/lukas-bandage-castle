## 1.1 Labb: Två belopp på samma faktura

### Symptom

Faktura #238 till Lord Malgrim the Unpleasant kostar 75 gp i listan, men 50 gp med märket v2 på detaljsidan. Billing v2 ska vara avstängt, så detaljsidan visar fel.

### Återskapa

1. Kör npm run db:reset och starta appen i en JavaScript Debug Terminal.
2. Logga in som admin och öppna Invoices. #238 kostar 75 gp.
3. Öppna fakturan. Den visar 50 gp och v2.

### Hypoteser

- Flaggan är påslagen. Test: läste .env. Resultat: ENABLE_BILLING_V2="false". Föll.
- Detaljsidan väljer v2 i routen. Test: brytpunkt på rad 30 i billing.routes.ts och laddade om fakturan. Resultat: programmet stannade i if (billingV2Enabled()), och Step Over gick in i if-satsen till legacyShapedInvoice. Höll.
- Koden tolkar flaggan fel. Test: Step Into till billingV2Enabled och Debug Console. Resultat: värdet är texten "false". !!process.env.ENABLE_BILLING_V2 ger true, och === 'true' ger false. Höll.

### Rotorsak

apps/api/src/legacy/billing/v2bridge.ts, rad 7, billingV2Enabled. Miljövariabler är alltid text. Koden gör om texten med !!, och all text som inte är tom blir true, även "false". Detaljsidan går därför till Billing v2, medan listan läser de gamla beloppen.

### Åtgärd

Jämför med texten: process.env.ENABLE_BILLING_V2 === 'true'. Då är v2 avstängt om inte texten är exakt "true", och ett stavfel stänger av i stället för att slå på. Kontroll: #238 visar 75 gp på båda sidorna, och ett test där flaggan är "false".

### Verktyg

- JavaScript Debug Terminal, för att kunna sätta brytpunkter i API:t.
- Brytpunkt på rad 30, som visade att detaljsidan går genom if-satsen.
- Step Into, för att komma in i billingV2Enabled och se värdet.
- Debug Console, där jag kunde jämföra !! med === 'true' med det riktiga värdet utan att ändra koden.
- Debuggern visar text med citattecken, "false", och booleans utan, false. Så ser man skillnad på en sträng och en bool. I Debug Console kan man också skriva typeof process.env.ENABLE_BILLING_V2 och få svaret 'string'.

### Reflektion

Vad gav Debug Console som jag inte kunde se i koden? Att värdet är texten "false" med citattecken. Läser man bara .env ser man false och tror att flaggan är av.

Hur hade jag hittat felet med console.log? Med en console.log på rad 7. Men console.log skriver ut false utan citattecken, så jag hade inte sett att det var text. Jag hade behövt lägga till typeof och starta om igen, alltså minst två omstarter.
