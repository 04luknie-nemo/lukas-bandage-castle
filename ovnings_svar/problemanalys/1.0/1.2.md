## 1.2 Felsök ett test

### Symptom

lateDays('2023-10-05', '2023-10-05T16:30:00') ger 1. Hämtning på avtalad dag borde ge 0. Testet för fallet är avstängt med it.skip.

### Återskapa

Brytpunkt på rad 15 i billing.ts. Kör npx vitest run apps/api/src/legacy/billing/billing.test.ts i en JavaScript Debug Terminal. Anropa funktionen i Debug Console.

### Hypoteser

- Testerna som körs täcker fallet. Resultat: de slutar på rad 15 och 18, inget når rad 19. Föll.
- Klockslaget ger en extra dag. Resultat: startOf('day') tar bort det. Föll.
- - 1 på rad 19 ger en extra dag. Resultat: out.diff(pickup, 'days') ger 0 i Debug Console. Höll.

### Rotorsak

billing.ts rad 19: out.diff(pickup, 'days') + 1. Samma fel som i Felsökning 3.3.

### Åtgärd

Ta bort + 1 och slå på testet. Kontroll: testet går igenom.

### Verktyg

Brytpunkt och F10 för att se var funktionen slutar. Call Stack för att se vilket test som anropar. Debug Console för att testa fallet som är avstängt.
